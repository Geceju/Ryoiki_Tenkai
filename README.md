This is a project for our Year 1 Tri 2 Digipen. It is called Gam 150, it is a game we made.
The game is called Ryoiki_Tenkai

Protagonist : Enoki Jogo

Threat : Carrot Kasuna

Objective : 
Escape 6 randomly generated levels in the fastest time possible by collecting keys randomly generated throughout the map with the aid of abilities

DESCRIPTION: 
Enoki Tenkai is a dungeon escape game, inspired by the anime Jujutsu Kaisen. 
The game takes place within a dice, therefore having 6 dynamic levels for players to get through before successfully escaping. 
The goal of the game is to escape 6 levels of randomly generated rooms in the shortest time possible by collecting keys randomly scattered throughout the map.
There are items that spawn around the map which the player can collect, providing them with abilities to aid their run.
Players need to get through all 6 levels with increasing difficulty with only 3 lives while escaping enemies hunting them down, with the choice of leaving on earlier levels.

CONTROLS:
Pressing F3 pops out a debug menu where there are other buttons shown that give different effects.
Editing the leaderboard.txt directly allows for cheated runs.

ADDITIONAL NOTES:

WARNING: This product contains horror elements and a scripted jumpscare. It is not recommended for players with heart conditions or sensitivity to sudden audio visual stimuli.

Gameplay tips:
- Try to loop enemies if they are chasing you, using obstacles to slow them down. This is the most effective way if you have no items.
- Items are limited, so use them when necessary. While ability durations are generous, players should prioritize collecting enough items before engaging in high-risk maneuvers.
- For higher levels, listening for the heartbeat sound is crucial. Since your FOV is smaller.
